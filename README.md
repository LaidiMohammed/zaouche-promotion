# ZAOUCCHE — Promotion Immobilière

Site vitrine TikTok-style, bilingue FR/AR, présentation front-end.

- **Live :** https://laidimohammed.github.io/zaouche-promotion/
- **Repo :** https://github.com/LaidiMohammed/zaouche-promotion
- **TikTok :** https://www.tiktok.com/@zaouche_promotion

## Dev
```bash
npm install
npm run dev
npm run build
```

## Phase 1 (actuelle)
Hero vidéo plein-écran, feed projets swipe, FR/AR RTL, navbar top desktop + bottom-bar mobile (Accueil / Nos Projets / À propos / Contact), page `/admin` placeholder.

## Phase 2 (à venir)
Supabase : login admin, CRUD projets, upload vidéo home, messages contact.
